# Campus42
@Depreceated
Even before the Covid-19 pandemic Universities were battling with falling student engagement, something that Campus42 aims to improve. This is a platform that combines the functionality of standard University apps and the familiarity of social media apps that we know.
## Project folders

| Folder      | Description |
| ----------- | ----------- |
| App      | The app that is the main focal point of this project       |
| Node   | Admin code that enabled remote maintenance of the project        |
| Server Side Functions | Automated maintenance scripts to run on a schedule |
| Firebase functions | Cloud based functions for the use from mostly the app |
| Api | Api that handles point triggers and analytics |
