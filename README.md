# App
This repo consists of the app specific code such as the Android and iOS code.

## Structure
The code is based on React Native and most of the editable code resides under `src`. Which has the two folders `assets` (General re-usable components) and `screens` (Navigational screens and their specific components).

## Getting Started
To run the app on your local computer you must follow these setup instructions: [React Native - Setting up the development environment](https://reactnative.dev/docs/environment-setup)

### Running
To start the code you should run the following commands dependent on desired platform from the root folder.
* `npm run ios`
* `npm run android`
